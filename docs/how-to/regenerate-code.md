# Regenerate code

Make the generated files agree with the manifest after a change, and commit them.

## Before you start

- The manifest compiles with no error.

## Steps

1. Change `domain.manifest.yaml`.
2. Run this command:

   ```bash
   npx urn-forge compile
   ```

3. Read each line of the output. `wrote` is a file that changed, `unchanged` is a file that did not change, and `removed` is a generated file that compile no longer makes.
4. If `compile` shows a diagnostic with `error`, correct the manifest and run it again. `compile` writes no file while the manifest has an error. Refer to [Diagnostics](../reference/diagnostics).
5. Run `npx urn-forge verify`, and do what it tells you. A new operation needs a function in the core; a new output or a new rule needs a scenario.
6. Commit the manifest and the generated files together.

## Example

After a change to the manifest, `compile` shows:

```
wrote      src/generated/domain.generated.ts
```

When nothing changed, it shows:

```
unchanged  src/generated/domain.generated.ts
```

With `postgres` in the config, `compile` also writes `schema.generated.sql` and `domain.store.generated.ts`. If you remove `postgres`, the next `compile` removes the two files:

```
unchanged  generated/domain.generated.ts
removed    generated/domain.store.generated.ts
removed    generated/schema.generated.sql
```

## Do not edit a generated file

Each generated file starts with this comment:

```
// Generated by urn-forge from domain.manifest.yaml. Do not edit: change the manifest, then run urn-forge compile.
```

The second line has the fingerprint of the file, the SHA-256 of its body. Gate 4 of `verify` compares each generated file with a new compile, byte for byte. A manual change fails gate 4:

```
gate 4  drift         FAIL  1 generated file(s) compared byte for byte against src/generated
    src/generated/domain.generated.ts:418  error  drift  the generated file is not current; run urn-forge compile
```

## Result

The generated files agree with the manifest, and gate 4 passes.
