# Regenerate the code

Compile again after a change to the manifest, and commit the generated files with it.

## Before you start

- You have a project that compiles. Refer to [Set up a project](set-up-a-project).
- If callers already use the manifest, check the change for breaks first. Refer to [Change the contract](change-the-contract).

::: warning
Do not edit the generated files. `compile` replaces them, and gate 4 fails until it does.
:::

## Steps

1. Run `npx urn-forge compile`. It writes each file that changed and removes each generated file that it no longer makes. If the manifest has an error, it writes no file.
2. Run `npx urn-forge verify`. A new operation needs a handler and a tagged feature. A new required input field needs a column in each input table.
3. Commit the manifest and the generated files in the same commit.

## Example

The maximum weight of tutorial 3 changes, and nobody runs `compile`. Gate 4 fails at line 2 of each file, the fingerprint line:

```
gate 4  drift         FAIL  2 generated file(s) compared byte for byte against tutorial/3-strict-coverage/src/generated
    tutorial/3-strict-coverage/src/generated/domain.runtime.generated.ts:2:1  error  generated-differs  differs from a fresh compile (hand-edited or stale); run `urn-forge compile`
    tutorial/3-strict-coverage/src/generated/domain.schemas.generated.ts:2:1  error  generated-differs  differs from a fresh compile (hand-edited or stale); run `urn-forge compile`
```

The fingerprint is a SHA-256 hash of the manifest, the plugins and the version of urn-forge. Each generated file starts with it:

```ts
// @generated by urn-forge 0.1.0 — do not edit
// fingerprint: sha256:492eef5cf4429536322062da365f080ff6cc4091bb6ae5563c713a73570b3b10
```

If you update urn-forge, the fingerprint can change with no manifest change. Compile again and commit the result.

## Result

`npx urn-forge compile` shows `unchanged` for each file:

```
unchanged  src/generated/domain.runtime.generated.ts
unchanged  src/generated/domain.schemas.generated.ts
fingerprint sha256:492eef5cf4429536322062da365f080ff6cc4091bb6ae5563c713a73570b3b10
```

Gate 4 of `npx urn-forge verify` passes.
